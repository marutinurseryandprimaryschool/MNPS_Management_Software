================================================================================
                              PRODUCT OVERVIEW
================================================================================

CampusOS is a modern, cloud-based School Management System designed specifically
for nursery and primary schools. It digitizes every aspect of school operations
— from student enrollment and attendance tracking to timetable scheduling, fee
management, marks/grades, and parent communication — all from a single,
beautifully designed web dashboard.

Built on enterprise-grade technology (Next.js + Firebase), CampusOS requires
zero server setup, works on any device with a browser, and scales effortlessly
from a 50-student nursery to a 1000+ student primary school.

================================================================================
                            KEY VALUE PROPOSITIONS
================================================================================

1. ZERO INFRASTRUCTURE COST
   - No servers to maintain. Fully cloud-hosted on Firebase.
   - Works on any device — desktop, tablet, or mobile phone.
   - No app installation required — runs entirely in the browser.

2. ROLE-BASED ACCESS FOR EVERYONE
   - Admins, Principals, Teachers, and Parents each get a tailored dashboard.
   - Google Sign-In for staff (secure, no passwords to remember).
   - Simple phone+DOB login for parents (no Google account needed).

3. ENTERPRISE-GRADE SECURITY
   - Firebase Authentication with Google OAuth 2.0.
   - Firestore Security Rules enforce role-based access at the database level.
   - Data encrypted in transit and at rest (Google Cloud infrastructure).

4. REAL-TIME DATA
   - All data updates in real-time across all connected devices.
   - Teachers mark attendance → Parents see it instantly.
   - Fee payments recorded → Dashboard stats update immediately.

5. BULK OPERATIONS
   - Import hundreds of students from Excel/CSV files in one click.
   - Intelligent column mapping supports 40+ field variations.
   - Auto-distributes students to sections based on Excel data.

================================================================================
                           USER ROLES & ACCESS
================================================================================

ROLE              ACCESS LEVEL
─────────────────────────────────────────────────────────────────────────────
Admin             Full system access. Manage all modules, users, settings.
Principal         Administrative access similar to Admin.
Correspondent     Administrative access similar to Admin.
Teacher           Attendance, marks, fees (collection), timetable (own classes).
Parent            View-only: child's attendance, marks, fees, timetable.
─────────────────────────────────────────────────────────────────────────────

AUTHENTICATION METHODS:
• Staff Login   → Google Sign-In (school-registered Google accounts)
• Parent Login  → Last 4 digits of phone number + Student Date of Birth
                  (No Google account required — uses Firebase Anonymous Auth)

FIRST-USER SETUP:
• The very first person to sign in is automatically made the Admin.
• Admin can then pre-register other users by email with assigned roles.
• When pre-registered users sign in with Google, they auto-receive their role.

                          TECHNICAL ARCHITECTURE
================================================================================

FRONTEND:
├── Framework      : Next.js 16 (App Router)
├── UI Library     : React 19
├── Language       : TypeScript 5
├── Styling        : CSS Modules + Global Design Tokens
├── Charts         : Recharts 3.8
├── Forms          : React Hook Form 7.72
├── Excel Import   : SheetJS (xlsx) 0.18
├── PDF Export     : jsPDF 4.2

BACKEND:
├── Database       : Firebase Firestore (NoSQL, real-time)
├── Authentication : Firebase Auth (Google OAuth + Anonymous)
├── Security       : Firestore Security Rules (role-based)
└── Hosting        : Vercel / any Node.js platform

DATA COLLECTIONS:
├── users          : User profiles with roles
├── students       : Student records (40+ fields)
├── teachers       : Teacher profiles with assignments
├── classes        : Class definitions with sections & subjects
├── timetables     : Timetable slots per class/section
├── attendance     : Period-wise attendance records
├── marks          : Exam marks with grades
├── feeStructures  : Class-wise fee configurations
├── feePayments    : Payment transaction records
├── assignments    : Class assignments
├── notifications  : System notifications
├── chats          : Chat messages (with subcollection)
└── school         : School settings (singleton)
